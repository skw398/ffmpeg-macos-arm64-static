# FFmpeg 9.0.2 configure detection notes (from n9.0.2/configure)
# - pkg-config STRICT (no fallback; must provide .pc): dav1d aom SvtAv1Enc
#   SvtJpegxs libssh rubberband vidstab libass freetype2 fribidi harfbuzz
#   libopenjp2 zimg libjxl libbluray dvdread dvdnav aribb24 libaribcaption
#   opencore-amrnb opencore-amrwb vo-amrwbenc srt librist libopenmpt lc3
#   oapv libchromaprint libmysofa libvvenc lcevc_dec xeve xevd libqrencode
#   tesseract libzmq caca librabbitmq lensfun OpenColorIO opus vorbis
#   theoraenc speex libwebp libwebpmux libxml-2.0 openssl harfbuzz
#   openh264 kvazaar libvpx(4 sub-checks w/ -lvpx fallback)
# - NO pkg-config (require/check_lib with -l flags): libmp3lame libsoxr
#   libcodec2 libgsm libilbc libflite libquirc libsnappy
#   (libtwolame uses require + extra symbol check)
# - libvvdec: NO option exists in 9.0.2 (only libvvenc)
# - astcenc: NO option exists in 9.0.2
# - liblcevc option is spelled --enable-liblcevc-dec
# - libxeveb/libxevdb are Base-profile variants; mutually exclusive with
#   libxeve/libxevd (configure dies if both enabled)
# - SDL2: pkg sdl2 >=2.0.1 <3.0.0 or sdl2-config fallback; ffplay hard-dep
# =====================================================================
