# flag-categories.txt — per-library フラグの分類（build-deps.txt の 3 列目）
#
# 規則は docs/BUILD-FLAG-CLASSIFICATION.md が正。ここは機械可読な一覧で、
# lint-workarounds.sh の [E] が build-deps.txt と突合し、dep は到達性まで見る。
#
# 形式: lib|flag|purpose|target|note
#
#   purpose  何のためのフラグか（これで「外せる」の確定方法が決まる）
#     build   ビルドが壊れるのを避ける      -> trial（外してビルドが通れば外せる）
#     dep     依存を避ける                 -> trial（ambient チェックが引き込んだ依存を捕まえる）
#     extras  余計なもの(tests/tools/docs)を作らない -> triage（no-op なら外せる）
#     find    prefix を見つけさせる         -> triage（未使用なら外せる）
#     feature 製品に入れる機能の選択         -> 人が要件と照らす（CI では決まらない）
#   target   dep のときだけ: 避けている依存（記録用。判定には使わない）
#   note     主に feature の「なぜ積むか」
#
# 方針系（static/共有）と標準ビルド設定、グローバルに隠れる -DBUILD_TESTING=OFF は
# 分類の対象外なのでここに載せない（lint [E] も除外する）。
