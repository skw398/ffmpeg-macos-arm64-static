# flag-categories.txt — per-library フラグの分類（build-deps.txt の 3 列目）
#
# 規則は docs/BUILD-FLAG-CLASSIFICATION.md が正。ここは機械可読な一覧で、
# lint-workarounds.sh の [E] が build-deps.txt と突合する。
#
#   T = trial 候補（環境の都合。drop_flags で外して試す）
#   G = triage 候補（テスト/ツール/docs 無効化、prefix ヒント。毎ビルドの triage が見る）
#   I = 意図（製品に入れる機能の選択。人が要件と見直す）
#
# 形式: lib|flag|category|note
#   note: 主に I の「なぜ積むか」。T/G では空。
#
# 方針系（static/共有）と標準ビルド設定、グローバルに隠れる -DBUILD_TESTING=OFF は
# 分類の対象外なのでここに載せない（lint [E] も除外する）。
