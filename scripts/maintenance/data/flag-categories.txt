# flag-categories.txt — classification of the per-library flags (column 3 of
# build-deps.txt)
#
# docs/BUILD-FLAG-CLASSIFICATION.md is the authority on the rules. This file is
# the machine-readable list; [E] of lint-workarounds.py cross-checks it against
# build-deps.txt (and for dep verifies reachability).
#
# Format: lib|flag|purpose|target|note
#
#   purpose  why the adopted flag exists (guides maintenance review)
#     build   avoid a broken build
#     dep     avoid a dependency
#     extras  omit unneeded tests/tools/docs
#     find    locate the adopted prefix
#     feature choose a product feature
#   Candidate removals are edits on feature, validated with a clean build and
#   reviewed against product requirements; the build does not read this file.
#   target   dep only: the dependency being avoided (for the record; not used in the decision)
#   note     mostly for feature: why it is included
#
# Policy flags (static/shared), standard build settings and the globally hidden
# -DBUILD_TESTING=OFF are not classified and are not listed here (lint [E] skips
# them too).
