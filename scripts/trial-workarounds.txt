# Ids of the workarounds a trial can disable (`NO_WORKAROUNDS` / workflow input
# `no_workarounds`). Listing an id here builds without that workaround, to decide
# whether it can be dropped. An unknown id fails the build (a typo must not turn
# into a trial that leaves every workaround in place).
# docs/BUILD-WORKAROUNDS.md is the authority on each workaround's "drop when".
#
# Reserved: `reset` disables nothing and only resets the cached build state
# (used when a per-library flag is trialed by hand; combine it with an id to
# reset and drop that id in one run).
#
# id|section|what the trial drops|affected libraries
#   The affected libraries are force-rebuilt by a fast trial (workflow input
#   trial_fast).
#     *      = affects every library (a fast trial cannot handle it: error)
#     ffmpeg = FFmpeg itself (a configure-argument change reconfigures via stamp)
#   A fast trial checks that these libraries were actually rebuilt.
size-t-preinclude|D|CXXFLAGS size_t.h forced include|*
autotools-touch|B|touch the generated autotools files|*
force-cpusubtype-strip|B|strip -force_cpusubtype_ALL from autotools configure|*
autotools-werror-strip|B|strip -Werror from the generated autotools Makefiles|*
cmake-werror-strip|B|strip a bare -Werror from the CMake sources|*
quirc-sdl-cflags|H|SDL_CFLAGS= on quirc's make line|quirc
ffmpeg-extra-libs|G|--extra-libs in FFmpeg's configure|ffmpeg
